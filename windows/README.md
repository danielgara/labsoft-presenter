# Presenter para Windows

`Presenter.exe` es para Windows 10 y Windows 11 de 64 bits (x64). No necesita instalación.

## Abrir

1. Descarga `Presenter.exe` y déjalo en una carpeta, por ejemplo Documentos o el Escritorio.
2. Ábrelo con doble clic.

La primera vez Windows puede bloquearlo porque el archivo no está firmado.

## Si Windows lo bloquea

Si aparece **Windows protegió su PC**:

1. Pulsa **Más información**.
2. Pulsa **Ejecutar de todas formas**.

Si el doble clic no hace nada, el archivo sigue marcado como descargado:

1. Clic derecho en `Presenter.exe` y elige **Propiedades**.
2. En **General**, marca **Desbloquear** si aparece, y pulsa **Aceptar**.
3. Ábrelo otra vez.

## Salir

**Salir**, en la barra, cierra Presenter. Cerrar solo la ventana de herramientas no sale de la app.

Para generar el exe de nuevo hace falta un PC con Windows y la rama `development`.
